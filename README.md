# Rock_paper_Scissors_with_python
A simple terminal game where you play Rock, Paper, Scissors against the computer.

## How to play
1. Run the game:
   python main.py
2. Type 0 for Rock, 1 for Paper, or 2 for Scissors.
3. The computer picks at random, and the game shows who wins.

## What I learned
- Lists and list indexes
- User input with `input()` and `int()`
- Random numbers with the `random` module
- If / elif / else logic
- ASCII art in Python
